The only icon style in the regroup: a Lucide-style line glyph, white, inside a filled circle. One set, so the "promised / delivered / faced" rows, arrow rows and KPI trends all match.
```jsx
<RegroupIcon name="check" />  <RegroupIcon name="arrow" color="#141414" />  <RegroupIcon name="alert" color="#5e5e64" />
```
- Glyphs drawn from Lucide paths. Need another one? Use Lucide at the same 2.6 stroke, white, in a circle.
- Regroup only: documents, decks and carousels stay icon-light (just `CheckIcon`).
