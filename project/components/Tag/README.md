Small square label for perks, facets and category headers.
```jsx
<div style={{display:"flex",gap:8}}><Tag>No expiration</Tag><Tag>Use across any project</Tag></div>
<Tag tone="outline" caps>Updated anti-fraud framework</Tag>
```
- `tone`: dark (default black chip), light (grey header pill e.g. "Government Entities"), outline, accent (lavender).
- `caps`: uppercase tracked style.
