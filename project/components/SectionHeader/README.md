Deck/page section opener — small bold eyebrow, then a full-sentence light-weight title.
```jsx
<SectionHeader eyebrow="Why Infoquest" title="Infoquest outperforms legacy expert networks on the four metrics that matter" />
```
- Title is a complete claim (action title), sentence case, no period.
- `lede` adds a bold 13px supporting paragraph. `inverse` for dark grounds.
